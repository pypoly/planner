### Личный трекер целей и задач
Веб-приложение для планирования и отслеживания целей с задачами и наглядным прогрессом выполнения.

### Возможности:
- Создание, редактирование и удаление целей

- Добавление задач к целям с чекбоксами выполнения

- Автоматический расчёт процента выполнения по каждой цели

- Зачёркивание выполненных задач и завершённых целей

- Светлая и тёмная темы с сохранением выбора

- Личный кабинет пользователя с привязкой целей к аккаунту


### Технологии:
- Backend: Python, Django
- База данных: SQLite
- Frontend: Bootstrap 5
- Инфраструктура: Docker, Nginx, Gunicorn
